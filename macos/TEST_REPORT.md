# macOS 0.1.0-preview.1 验收记录

日期：2026-09-17。程序与源码包来源提交：`95bd0ed0e78e4c3bed1a3e7310965fa59f1b11b6`。

[最终 GitHub Actions 运行](https://github.com/turnsolesama/proxy-switch/actions/runs/35221260172)中，`macos-15 / arm64` 与 `macos-15-intel / x86_64` 两项任务均成功。最低构建目标为 macOS 13；13/14 系统没有独立运行验收。

## 已执行

- 两种架构分别通过 `swift test` 的 8 项策略回归：域名 / 程序优先级、默认不允许直连、保留健康备用及未知状态、明确允许直连、重建时保留已选出口、拒绝入口回环与规则注入、保留未知和远程配置、恢复归属与绕过列表。
- `--system-selftest` 使用真实 SystemConfiguration API 对独立临时 preferences 文件进行测试：接入读回、旧本机端口关闭后的恢复、PAC / 绕过保留、外部改动保留、混合归属冲突阻止停止、明确触发失效入口修复。该步骤在 CI 提升权限运行，**没有操作默认系统 preferences，也没有调用实际网络 ApplyChanges**；不等同普通用户授权弹窗验收。
- 原生程序导出配置，由随包真实 mihomo 校验并运行；本地合成上游 A / B 与 HTTP 目标实际完成 A → B → 直连 → B、域名例外、关闭 A 后选择 B、REJECT 不回落直连、错误控制器密钥拒绝访问。自动接替决策由策略回归覆盖；这里的出口选择是测试主动驱动，不宣称已经完成真实客户端全程自动切换验收。
- AppKit 窗口实际启动、应用正常退出及控件基础断言；检查原生窗口截图，文字与操作区域可读。窗口关闭后菜单栏驻留的人工交互仍需真机复测。
- 核对原生架构及 ad-hoc 签名；对 ZIP 解压后的搬迁副本再次核对签名并执行真实请求测试。
- 上游压缩包按锁文件 SHA-256 校验，内核许可证和完整对应源码随包分发。安装包仅包含应用资源，没有个人配置或控制器密钥。
- 发布草稿上传后重新下载；公开后通过无账号凭据的下载 URL 完整下载两个应用 ZIP、源码 ZIP、摘要和清单，核对大小、SHA-256、CRC、无重复 / 越界 / 链接条目、单应用根目录、执行位及全部应用文件清单。

## 仍需真实 Mac 复测

1. Gatekeeper 首次打开和系统网络授权的同意 / 取消；无 Developer ID 证书，不宣称通过公证。
2. 用户真实上游和应用的 A → B → 直连 → B、新请求的实际出口、程序路径及联网子进程识别、真实账号登录。
3. 退出上游后的自动备用、全部上游失败、界面意外退出、内核崩溃、后台工作进程被强制结束后的残留恢复。
4. Wi-Fi / 有线网络切换、新增服务、睡眠唤醒、其他 VPN / TUN 或代理守护并存、长时间运行。
5. 当前应用忽略系统代理或缓存旧入口时的处理。流向不结束用户应用，也不能保证网络本身故障时全部网站可用。

这是原生可运行测试包，不是 iOS 版、网页演示或完整 Windows 功能等价版。此轮只新增 Mac 源码和包；没有替换本机 Windows 安装或修改其系统代理。
