# 流向 FlowSwitch · macOS 测试版 0.1.0-preview.1

原生 AppKit 桌面程序，macOS 13 及以上，分别构建 Apple 芯片 arm64 和 Intel x86_64。程序包自带锁定的 mihomo 1.19.29，不需要安装 Node、Python、Homebrew 或 Clash。仍需要用户自己的无认证 HTTP / SOCKS5 上游，不提供节点、订阅或 VPN 服务。

## 安装与使用

1. 下载对应架构 ZIP，完整解压，把 FlowSwitch.app 拖到“应用程序”。当前包仅有 ad-hoc 完整性签名，没有 Developer ID 公证。系统可能拦截首次打开；请核对来源和 SHA-256，再按 macOS“隐私与安全性”提供的单个应用打开选项操作。无需关闭全局系统安全保护。
2. 打开已有代理客户端，关闭其系统代理守护及 TUN，保留本地代理监听。流向不会替你关闭这些开关。
3. 添加 HTTP / SOCKS5 主机和端口，选择默认线路。点击“接入系统代理”，实际请求检测通过后，macOS 会请求修改网络设置授权。取消授权不会接入。
4. 每条代理线路以其他已添加线路作为备用，按列表顺序检测；失败连续三轮后切到可用备用，健康备用不会自动回跳。全部失败默认暂停，只有明确勾选才允许直连。健康探测约每 8 秒一轮，另有请求耗时，切换不保证零中断。
5. 可以添加精确域名、域名及子域、完整程序可执行路径规则。域名更具体者优先，同域名精确匹配优先，网站规则优先于程序规则。规则修改需先停止服务再接入。切换默认线路保留例外。
6. 点击关闭窗口后继续在菜单栏运行。“停止并恢复”或菜单栏“停止服务并退出”先恢复仍属于流向的系统设置，再停止自有内核。原备份内的本地代理已确认关闭时，会关闭该失效项，而不是恢复死端口。

## 故障排查与恢复

“排查网络”只读显示系统入口和本地端口状态。“修复失效入口 / 恢复残留”需要明确点击，可恢复流向遗留记录，并关闭双重确认拒绝连接的本机 HTTP/HTTPS/SOCKS 设置；远程、PAC 和未知状态保留。

后台工作进程负责内核与恢复。窗口进程意外退出后会尝试恢复；内核崩溃最多在五分钟内重启三次，保留当前备用选择。无法恢复时保留内核并显示错误，不报告已退出。后台进程被强制杀死或断电不保证即时恢复；下次打开后使用“恢复残留”。不会自动启动代理或覆盖其他软件的新设置。

数据只在 `~/Library/Application Support/FlowSwitch`，权限限制为当前用户。停止后再升级；不要公开其中的配置、控制器密钥和恢复记录。保留该目录可以接续修复。

## 明确的功能边界

- 管理启用网络服务的手动系统代理，不启用 TUN、不更改 DNS、路由或全局环境变量。新增网络服务后需要停止再接入。
- 只有遵守系统代理或手动配置为流向入口的流量进入内核。UDP / QUIC、自带 VPN、忽略系统代理的应用不保证覆盖。
- 程序路径规则依赖 mihomo 在当前用户权限下识别实际联网进程。子进程应分别添加其真实可执行路径；无法识别时按网站或默认规则处理。不能把保存了规则说成已经验证所有应用流量。
- 健康检测使用 Google / Microsoft 的两个固定连通性地址，任一成功即可，避免单站点故障被误认为线路全部失效。探测成功不是账号登录成功，也不保证所有站点正常。
- HTTP/SOCKS5 账号密码、自动发现第三方入口、订阅导入、Windows 专用快捷方式适配不在本次测试版中。
- 没有 Apple 开发者账号，不能提供 Developer ID 签名和公证。GitHub Mac 自动构建 / 隔离测试不能代替用户机器上的授权弹窗、真实应用归属、网络切换与长期稳定性验收。

## 构建与验证

在 Mac 安装 Xcode Command Line Tools，运行：

```sh
cd macos
swift test
sudo -v # 仅用于隔离的临时 preferences API 测试；不修改真实网络配置
python3 scripts/build.py --arch arm64 --output ../dist/mac-arm64
# Intel 机器使用 --arch x86_64
```

构建脚本核对官方组件压缩包 SHA-256，编译原生程序，打包对应源码和 GPL-3.0 许可证，核对签名 / 架构，执行 AppKit 窗口冒烟及真实本地 A/B/直连请求测试，最后解压安装包并再次验证。没有在 CI 写入真实系统代理；恢复策略的自动化覆盖与实际系统授权测试必须区分。

FlowSwitch 自有代码按仓库 MIT 许可证发布；mihomo 为独立随包组件，遵循其 GPL-3.0 许可证，包内提供锁定版本的完整对应源码。源码包不包含个人设置。
